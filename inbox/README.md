# Inbox

This is the place for **files and complete protocols**. Comments, observations and findings go through [STAR-T-GATE](https://www.tiveritllc.com/star-t-gate.html), the official comment channel for all TIVERIT open-source repositories. [Upload here](https://github.com/gschmidtke/ARPL/upload/main/inbox) into `inbox/<your-github-name>/<short-title>.json` (use [the template](../templates/submission.template.json)), or Markdown, logs or a zip in the same folder.

You don't need to fit the library structure. The curator reviews everything in this folder, files it into `library/`, records the decision in [the ledger](../ledger/intake-ledger.json), and moves the original to `ledger/archive/`. See [CURATION.md](../CURATION.md).
